Publishing

Publish saves your changes straight to your GitHub repo. It needs a key that can only touch that one repo.

  1. On GitHub, open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it “Portfolio editor”, and pick an expiry (a year is fine).
  3. Repository access: Only select repositories → your portfolio repo.
  4. Permissions → Repository → Contents: Read and write. Nothing else.
  5. Generate, copy it, and paste it below. It stays on this device only.
